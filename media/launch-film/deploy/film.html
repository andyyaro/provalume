Transcript

Your coding agents forget. One learns that the integration suite deadlocks. On Tuesday, the next one tries it again. Most agent memory keeps what an agent said.

Provalume keeps what was proved.

A command that passed. A reviewer who wasn't the author. A commit that actually landed.

Every memory climbs five rungs of trust, and none can be skipped. Agents propose. They never promote.

So before an agent repeats a failure, it's warned, with the evidence.

No LLM. No API key. No network. 777 tests, all passing. Open source, on PyPI.
